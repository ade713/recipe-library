# Recipe Library Design

These wireframes explore the mobile-first UI direction for Recipe Library.

## Current direction

Option C is the preferred direction. It uses a warm, approachable visual style designed to feel clear and comfortable while browsing recipes or cooking.

## Wireframe backlog

Consider these in later wireframe rounds:

- Ingredient and instruction editing interactions
- Partial import with missing fields and parser warnings
- Focused failed or blocked import flow
- Recipe saving progress, success, and failure states
- Loading, network-error, and expired-session states
- Account details
- Ingredient scaling when a line cannot be scaled confidently

The final UI direction has not been formally approved. Option C should guide future exploration unless a later documented decision replaces it.
